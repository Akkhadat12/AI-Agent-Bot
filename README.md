# AI Agent Bot — Why Now and Where It Works

เอกสารวิจัยและบรีฟสำหรับสร้าง **เว็บภาพประกอบการเล่าเรื่อง YouTube** หัวข้อ: ทำไมบริษัท AI จึงเร่งสร้าง Agent Bot ทั้งที่ยังไม่คุ้มกับทุกงาน และงานประเภทใดมีโอกาสได้ประโยชน์จริง

**ประเด็นที่เลือก:** Agent ที่ลงมือทำงานในเครื่องมือจริงอาจสร้างคุณค่าให้ผู้ใช้และธุรกิจของผู้ให้บริการ แต่หลักฐานปัจจุบันยังไม่พอจะสรุปว่า Agent แบบอัตโนมัติคุ้มค่าในทุกอุตสาหกรรม การประเมินต้องดูผลลัพธ์ ต้นทุน การตรวจสอบ และสิทธิ์ในการทำงานเป็นรายงาน/รายกระบวนการ

**สถานะ (27 ก.ย. 2026):** วิจัย วิเคราะห์ วางโครงเรื่อง บรีฟสร้างเว็บ และแผน QA พร้อมแล้ว; ยังไม่มีเว็บที่สร้างและผ่าน QA ตามบรีฟชุดนี้ อย่าถือว่าไฟล์นี้คือเว็บไซต์สำเร็จหรือผลทดสอบจริง

## ขั้นตอนถัดไปสำหรับผู้สร้างเว็บ

1. อ่าน `01`–`05` ตามลำดับ โดยใช้ `02` เป็นฐานตรวจข้อเท็จจริง และ `03` เป็นลำดับการเล่าเรื่อง ตรวจแหล่งต้นทางใหม่ก่อนเผยแพร่หากสถานะผลิตภัณฑ์หรือข้อมูลเปลี่ยน
2. สร้างเว็บภาพประกอบ 2D ใน **repo นี้บนสาขา `main`**: Cover → S1–S7 → Closing เนื้อหาที่เห็นบนเว็บเป็นภาษาอังกฤษน้อยคำ ส่วนการวิเคราะห์ภาษาไทยอยู่ในเอกสาร/คำบรรยายของผู้เล่า หนึ่งหน้าสื่อหนึ่งแนวคิด และทุกหน้าค้างนิ่งให้พูดประกอบได้นานตามต้องการ
3. ใช้ภาพอ้างอิงจริงที่จำเป็นใน Cover/S2 และพิจารณาภาพตัวอย่างงาน Support ใน S4 ตาม `04` ภาพใน `references/` เป็นไฟล์ต้นทางสำหรับจัดวาง ยังไม่ใช่ artwork ของหน้าสำเร็จ ควรออกแบบองค์ประกอบและ motion ตามตารางรายหน้าใน `04` โดยไม่สร้างภาพ AI แทนเครื่องหมาย/อินเทอร์เฟซทางการ
4. ทำให้คลิกวัตถุในเรื่องเพื่อเปลี่ยนหน้าได้; Space เดินหน้า 1 หน้า, R กลับ Cover; ไม่เล่นหน้าเองและไม่วน animation เรื่อย ๆ ต้องใช้ได้ทั้งเฟรมบันทึก 16:9 และหน้าจอมือถือ พร้อมรองรับ reduced motion
5. เก็บ source, asset ที่เสิร์ฟจริง และ `BUILD_NOTES.md` ลง repo; เผยแพร่ **production URL สาธารณะ** ที่เปิดได้โดยไม่ต้องล็อกอิน จากนั้นทำ QA ตาม `05` บนหน้าเว็บจริง แก้จุดที่ไม่ผ่านและทดสอบซ้ำ
6. หลังเว็บสุดท้ายเผยแพร่แล้ว ส่ง `06_SCENE_RATIONALE.docx` ภาษาไทยพร้อมภาพแต่ละหน้าลง [Drive โฟลเดอร์เดียวกัน](https://drive.google.com/drive/folders/1lIkUlxdnk0A_xEKz5oYM5NfUfZWFSmV1) และเก็บ `07_WEB_QA_REPORT.md` พร้อมหลักฐานตรวจและผลหลังแก้ไว้ใน repo ส่งลิงก์เว็บจริง ลิงก์ Word, QA report และ commit สุดท้ายให้เจ้าของงาน

**หลักฐานสำคัญ:** ผล 99% ของงานคืนเงินเป็นคำรายงานของผู้ให้บริการในระบบ Support ของตน; งานวิจัย NBER ที่พบผลผลิตเฉลี่ย +14% ศึกษา AI ช่วยพนักงาน ไม่ได้ทดสอบ Grok Bot; ผลงานเขียนโค้ดของ METR มีขอบเขตผู้ร่วมทดลองและช่วงเวลาเฉพาะ อ่านเงื่อนไขใน `02` ก่อนนำตัวเลขขึ้นเว็บ ห้ามรวมผลต่างวิธีวัดเป็นกราฟเปรียบเทียบเดียวกัน

**ขอบเขตของ repo ณ ตอนนี้:** เป็น handoff สำหรับผู้สร้างเว็บและผู้ตรวจ QA ยังไม่มี URL เว็บที่ผ่านเกณฑ์ `05`; เมื่อส่งมอบจริงให้อัปเดตสถานะและเพิ่มลิงก์ production URL ที่นี่ด้วย
